IMMINENCE VJ PACK - HOW TO INSTALL (Resolume Arena 7, Windows)
================================================================

1. Close Resolume Arena.

2. Copy every IMMINENCE_*.dll file from this folder into Arena's plugin folder:

      Documents\Resolume Arena\Extra Effects

   If that folder does not exist, create it. (Arena's Preferences show which folder it reads
   extra plugins from, if yours is somewhere else.)

3. Open Arena. Search "IM " in the Effects, Sources and Transitions lists to find everything.

4. Unlock: add any IMMINENCE effect, find the "Unlock code" box at the bottom of its
   controls, type your code and press Enter. Every IMMINENCE plugin on this computer unlocks,
   and stays unlocked. Without the code everything still works, with an IMMINENCE watermark.

If Windows blocked the download: before unzipping, right-click the zip > Properties > tick
"Unblock" > OK, then unzip again.

Full guide: https://github.com/IG10000/resolume-addons
