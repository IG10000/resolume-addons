**IMMINENCE VJ Pack for Resolume Arena 7 (Windows, 64-bit)**

Download **IMMINENCE-Windows.zip** below, unzip it, and copy the `.dll` files into
`Documents\Resolume Arena\Extra Effects`. Then restart Arena. Full steps are in the
[README](https://github.com/IG10000/resolume-addons#readme).

29 plugins:

- **Effects:** IM Slice Trace, IM Halo, IM Borders, IM Aura, IM Live Looks, IM Live FX, IM Caustics, IM Ink, IM Reveal,
  IM Type, IM Stylize, IM Echo, IM Melt, IM Time
- **Sources:** IM Type Source, IM Slice Src, IM Halo Src, IM Borders Src, IM Caustics Src
  (border and overlay looks as their own see-through clips)
- **Transitions:** IM Liquid Wipe, IM Flash Burn, IM Whip Zoom, IM Slice Slide, IM Smoke Reveal, IM Pixel Stream,
  IM Halo Iris, IM Cube Turn, IM Glow Dissolve, IM Spectrum

Without the unlock code every plugin works with an IMMINENCE watermark.
